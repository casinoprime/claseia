# ClaseIA

Next.js + Supabase app para transcribir clases universitarias y estudiar con IA.

## Stack
- Next.js 16
- Supabase Auth, Postgres y Storage
- Groq para transcripción

## Variables de entorno
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- GROQ_API_KEY

La app arranca vacía, sin clases ni datos de demostración.
